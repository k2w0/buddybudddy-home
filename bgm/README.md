# 버디 BGM 목록 (광고 없는 기본 배경음악)

이 폴더의 음악 파일은 모든 미니홈피(웹/모바일)의 주크박스 → **배경음악 등록 → 🎼 버디 BGM** 탭에 나와요.
모바일 홈피도 이 폴더(`https://k2w0.github.io/buddybudddy-home/bgm/`)를 같이 써요.

## 곡 추가하는 법

1. 음악 파일(mp3, m4a, ogg, wav)을 이 폴더에 올려요. 파일 이름은 영어/숫자로 하는 걸 추천해요. 예: `spring-day.mp3`
2. `list.json` 에 한 줄 추가해요.

```json
[
  { "id": "spring-day", "title": "봄날 산책", "artist": "버디밴드", "file": "spring-day.mp3" }
]
```

- `id`: 영어/숫자/`-`/`_`/`.` 만 (한 번 정하면 바꾸지 마세요. 친구들 주크박스가 이 id로 곡을 찾아요)
- `file`: 이 폴더에 올린 파일 이름 그대로

## 주의

- 저장소가 공개라서 **누구나 파일을 내려받을 수 있어요.**
  저작권이 있는 노래(가수 음원 등)는 올리면 안 되고, 직접 만든 곡이나
  유튜브 오디오 보관함 · 픽사베이 뮤직처럼 **무료로 배포해도 되는 곡**만 올려 주세요.
- GitHub 파일 하나는 100MB, 저장소 전체는 1GB 안쪽으로 유지해 주세요. (곡당 3~5MB 권장)
