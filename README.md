# 버디버디 미니홈피 (웹용)

버디버디 메신저와 같은 Firebase 프로젝트(`buddy-buddy-fbafe`)를 쓰는 미니홈피입니다.

- 주소: `https://k2w0.github.io/buddybudddy-home/?uid={아이디}`
- 메신저(`https://k2w0.github.io/buddybudddy/`)에서 로그인한 상태가 그대로 이어집니다.
- 로그인한 사람이 홈피 주인이면 관리 화면, 아니면 방문자 화면으로 열립니다.
- 데이터 구조와 보안 규칙은 메신저 저장소의 `DATA_STRUCTURE.md`, `database.rules.json` 을 따릅니다.
